# Non-Functional Requirements (global)

> 로컬 macOS 메뉴바 앱이라 서버 템플릿의 SLA·처리량·RPO 항목은 "해당 없음"이다. 숫자는 **초안 목표**이고, 첫 Bolt에서 실측한 뒤 조정한다(표시: `목표(실측 후 조정)`).

## 안전성 (Safety) — 최우선

| ID | 요구사항 | 검증 방법 |
|---|---|---|
| NFR-S1 | 먹이 카탈로그에 정의된 경로 패턴 **밖의 경로는 어떤 경우에도 이동·삭제하지 않는다** (allowlist) | 카탈로그 밖 경로를 넣은 단위 테스트에서 거부 |
| NFR-S2 | 안전 등급 `X` 경로는 하드 deny-list로 막는다. allowlist 매치보다 우선한다 | deny-list 경로 테스트 |
| NFR-S3 | 실행 직전 재검증: 승인 시점 이후 대상이 바뀌었으면(경로 존재, symlink 대상, worktree의 커밋 안 된 변경, 관련 도구 실행 여부) 그 항목은 실행하지 않고 사용자에게 알린다 | 승인 후 상태를 바꾸는 통합 테스트 |
| NFR-S4 | symlink는 따라가지 않는다. 해석된 실제 경로가 allowlist 밖이면 거부한다 | symlink 픽스처 테스트 |
| NFR-S5 | 휴지통으로 보낼 수 있는 먹이는 항상 휴지통으로 보낸다(C2, D4). 앱은 휴지통을 비우지 않는다 | 코드 경로 검사 + 테스트 |
| NFR-S6 | 복구 불가 먹이(도구 명령형, C3)는 ① "복구 불가" 표시 ② 실행할 명령 원문 미리보기 ③ 두 번째 확인을 모두 거친 뒤에만 실행한다 | UI 테스트 |
| NFR-S7 | 모든 먹기 동작을 로컬 먹은 기록에 남긴다: 시각, 원래 경로, 크기, 휴지통 경로(또는 실행한 명령), 결과 | 기록 파일 검증 |
| NFR-S8 | 카탈로그 경로는 **경로 전체 일치**로 판정한다. 접두사 매치를 쓰지 않고, 먹이는 부모 폴더가 아니라 하위 경로 단위로 정의한다(카탈로그 CR-1·CR-2). 예: `~/.android/avd`는 먹이지만 옆의 `~/.android/debug.keystore`는 X | 이웃 X 경로 픽스처 테스트 |
| NFR-S9 | 도구 명령은 셸 문자열이 아니라 **실행 파일 절대 경로 + 인자 배열**로 실행한다. 경로가 인자에 들어가도 셸 해석이 일어나지 않는다 | 공백·따옴표·`;`가 든 경로 픽스처 테스트 |

## 프라이버시 (Privacy)

| ID | 요구사항 | 검증 방법 |
|---|---|---|
| NFR-P1 | 기본 설정에서 앱이 외부로 보내는 네트워크 요청은 **0건**이다(텔레메트리 없음) | `nettop` 등으로 실행 중 네트워크 관찰 |
| NFR-P2 | LLM 연결(D6, MVP 이후)을 켜더라도 **파일 내용은 절대 보내지 않는다**. 보내는 것은 경로·크기·시각 같은 메타데이터뿐이고, 보내기 전에 사용자가 내용을 볼 수 있다 | 전송 페이로드 테스트 |
| NFR-P3 | 먹은 기록과 경험치는 로컬에만 저장한다 | 저장 위치 검사 |

## 성능·자원 (Performance)

| ID | 요구사항 | 비고 |
|---|---|---|
| NFR-F1 | 홈 디렉터리 기본 경로 스캔(프로젝트 스캔 루트 제외): p95 ≤ 60초 | 목표(실측 후 조정) |
| NFR-F2 | 프로젝트 스캔 루트 스캔은 진행률을 보여 주고 언제든 취소할 수 있다 | 시간 목표는 첫 Bolt 실측 후 설정 |
| NFR-F3 | 스캔하지 않을 때 CPU 사용률 평균 ≈ 0% (Activity Monitor 기준 0.5% 미만) | 목표(실측 후 조정) |
| NFR-F4 | 백그라운드 스캔은 낮은 우선순위(QoS utility 이하)로 실행한다 | 코드 검사 |
| NFR-F5 | 메뉴바 상주 메모리 ≤ 150 MB | 목표(실측 후 조정) |

## 권한 (Permissions)

| ID | 요구사항 |
|---|---|
| NFR-A1 | App Sandbox를 쓰지 않는다(C1, 직접 배포) |
| NFR-A2 | macOS 권한(예: 다른 앱 데이터 접근)은 필요한 먹이를 처음 다룰 때만 요청하고, 거부되면 그 먹이만 건너뛴다. 다른 먹이 처리는 계속한다. 다른 앱 데이터 컨테이너(`~/Library/Containers/…`)는 열거하지 않고, 크기는 그 도구의 명령으로 잰다(예: `docker system df`, 카탈로그 CR-10) |
| NFR-A3 | Full Disk Access를 기본 요구사항으로 두지 않는다 |

## 배포·호환성 (Distribution)

| ID | 요구사항 |
|---|---|
| NFR-D1 | Developer ID로 서명하고 공증(notarization)해 Gatekeeper 경고 없이 실행된다 |
| NFR-D2 | Homebrew cask(개인 tap)로 설치·업그레이드할 수 있다. MVP는 앱 내 자동 업데이트를 넣지 않는다 |
| NFR-D3 | 최소 macOS 14 (P2) |
| NFR-D4 | Apple Silicon 지원. Intel 지원 여부는 **미정**(open question) |

## 사용성 (Usability)

| ID | 요구사항 |
|---|---|
| NFR-U1 | UI와 캐릭터 대사는 한국어 기본, 영어 지원 |
| NFR-U2 | 메뉴바 항목과 버튼에 VoiceOver 레이블을 단다 |
| NFR-U3 | 먹기 전 화면에 항목별 크기, 안전 등급, 재생성 방법(지웠을 때 무엇이 다시 만들어 주는가)을 보여 준다 |

## 운영성 (Operability)

| ID | 요구사항 |
|---|---|
| NFR-O1 | 먹이 카탈로그는 코드와 분리된 데이터(버전 번호 포함)로 관리해, 경로 추가·수정이 앱 로직 변경 없이 가능하다 |
| NFR-O3 | 경로는 도구가 알려 주는 값(`brew --cache`, `go env`, `pnpm store path` 등)을 먼저 쓰고, 기본 경로는 도구가 없을 때만 쓴다(카탈로그 CR-3). 어느 값을 썼는지 진단 로그에 남긴다 |
| NFR-O2 | 진단 로그는 로컬 파일로만 남기고, 파일 내용은 기록하지 않는다 |

## 해당 없음

- Scalability, Availability(SLA/RPO/RTO), Cost per request: 서버가 없는 로컬 앱이라 해당 없음

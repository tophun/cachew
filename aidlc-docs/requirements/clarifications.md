# 명확화 답변 (Inception Step 2)

질문 배경은 `plans/inception_plan.md` Step 2에 있다. 아래는 2026-10-30 사용자 답이다.

| # | 질문 | 답 | 이후 단계에 주는 영향 |
|---|---|---|---|
| C1 | 배포 방식 | **직접 배포.** Developer ID로 서명·공증하고 Homebrew cask 또는 DMG로 배포한다. App Sandbox는 쓰지 않는다 | 캐시 경로에 직접 접근 가능. 다른 앱 컨테이너(예: Docker Desktop) 접근 시 macOS 권한 프롬프트 여부는 카탈로그의 "권한 필요" 열에서 확인. App Store 배포는 범위 밖 |
| C2 | 휴지통에 보낸 파일이 공간을 계속 차지하는 문제 | **휴지통 + 비우기 안내.** 휴지통으로 보내고 "휴지통을 비우면 N GB 확보"라고 안내한다. 비우기는 사용자가 직접 한다 | D3·D4 원칙 유지. 앱이 휴지통을 비우지 않으므로 추가 권한이 필요 없다. 기술 검증(Step 3)은 생략. 경험치(D7)를 휴지통 이동 시점에 줄지, 비운 뒤에 줄지는 Step 5에서 확인 |
| C3 | 휴지통에 넣을 수 없는 먹이(Docker 이미지·볼륨, 시뮬레이터 런타임 등) | **MVP에 포함하되 "복구 불가"로 표시**하고, 한 번 더 확인받은 뒤 각 도구 명령을 실행한다 | D4의 예외로 기록. 카탈로그에 "휴지통 가능 여부"와 "도구 명령" 열이 필수. 복구 불가 먹이는 일반 먹이와 다른 확인 흐름이 필요(user story에 반영) |

## 기본값 확정 (level1_plan 승인과 함께)

- P1: MVP는 메뉴바 앱이다. 스캔 엔진은 UI와 분리된 모듈로 만들고, CLI는 후속 Bolt에서 붙인다
- P2: 최소 지원 OS는 macOS 14다
- P3: 성공 지표 초안 — 오삭제 0건, 동료 설치 5명 이상, 1인당 첫 주 확보 용량 기록(Step 8에서 확정)
